# Sora-2 Pro Control (Flutter)

Минимальное кроссплатформенное приложение на Flutter для базового взаимодействия с устройством **Sora-2 Pro**. Реализованы панели управления и телеметрии, а также заготовки для интеграции с реальным API.

## Основные возможности
- Отображение статуса устройства и его IP-адреса.
- Управление режимами (Auto/Manual/Safe) и командами запуска/остановки.
- Получение телеметрии (температура, заряд батареи, уровень сигнала) с возможностью ручного обновления.
- Структура на Riverpod для удобного расширения и интеграции с реальными сетевыми вызовами.

## Структура проекта
- `lib/main.dart` — точка входа, навигация и основной экран.
- `lib/services/sora_api.dart` — слой работы с API (реальные HTTP-вызовы к контроллеру Sora-2 Pro).
- `lib/models/device_state.dart` — модели состояния устройства и телеметрии.
- `lib/widgets/` — виджеты панелей управления и телеметрии.

## Настройка и запуск
1. Установите Flutter (3.3+). Например, через `fvm` или официальные инструкции.
2. В корне проекта выполните:
   ```bash
   flutter pub get
   flutter run
   ```
3. Перед запуском укажите адрес контроллера и креденшелы для Basic Auth через `--dart-define` (они попадут в `SoraApiConfig`):
   ```bash
   flutter run \
     --dart-define=SORA_API_BASE_URL=https://192.168.0.88 \
     --dart-define=SORA_API_USER=admin \
     --dart-define=SORA_API_PASS=secret
   ```
4. Реализация `SoraApi` уже использует реальные HTTP-вызовы к контроллеру Sora-2 Pro, остаётся только подставить ваши адрес и креденшелы.
